## 四、按角色的完整使用流程（HR 视角 + 各角色视角）

### 4.1 HR 管理员（人力资源核心流程）⭐

```
登录(hr_admin)
  → ① 配置报销类型（限额/发票要求/分组）—— 可对话式："新建差旅类型，每日500"
  → ② 维护报销组（聚合类型、生效日期、可见角色）
  → ③ 设计报销权益（按 P3-P7 职级差异化，对齐市场75分位）
  → ④ 生成权益流程（AI 一键跑批生成全员年度权益包）
  → ⑤ 查看合规视图（7 国税务/政策对照）
  → ⑥ 导出福利使用报表（Excel / PPT）
权限：13 项；红线：无权调整余额（需财务/系统管理员）
```

### 4.2 员工（自助报销流程）

```
登录(employee) → 我的余额摘要 → 新建报销
  → 上传票据(OCR自动识别商户/金额/类别) → 选报销类型/家属 → 提交
  → AI(ClaimMate)自动校验限额合规 → 进入审批流
权限：4 项；红线：无审批权（越权时 AI 优雅引导）
```

### 4.3 审批人

```
登录(approver) → 待审清单(AI已做风险分级:🟢🟡🔴)
  → 单笔/批量审批/拒绝/退回(保留退回历史) → AI(ApprovalCopilot)给出建议
权限：6 项
```

### 4.4 薪资专员

```
登录(payroll) → 报销接口流程 → 审核接口数据 → 汇率维护
  → AI(PayrollNavigator)跑批校验(126条/0异常) → 生成付款文件
权限：3 项
```

### 4.5 财务 / 审计

```
登录(finance) → 合规风险分析(InsightOracle) → 余额调整(增/减/转移,强制留痕)
  → 审计日志追溯 → 跨境税务核算
权限：3 项（含独占的余额调整权）
```

### 4.6 系统管理员

```
登录(sys_admin) → AI配置后台(API平台/模型/Agent分发,Key加密)
  → 13智能体遥测监控 → 全模块管理 → 全量审计
权限：16 项（admin=true，最高权限）
```

## 五、问题清单与处置建议

> 走查未发现"功能跑不通 / 拿不到数据"的硬伤。以下为体验增强项，按优先级排列。

### 🟡 P1 — 体验可增强（建议排期优化）

**问题 1：sys_admin 问"13 个智能体运行状态"被路由到报销数据分析**
- **现象**：自然语言问运维状态，IntentAgent 识别为数据洞察 → InsightOracle 回了报销概览，未回 telemetry 真实状态。
- **根因**：意图识别缺少"系统运维/遥测"意图分支。
- **建议**：在 IntentAgent 增加 `system_ops` 意图，命中后直接渲染 `/api/telemetry` 的 13 智能体实时面板。
- **影响**：低（左下角 AI Core 面板已实时展示该数据，仅聊天问答未对齐）。

**问题 2：HRStrategist 对"翻译成计算公式"类请求只给政策建议**
- **现象**：hr_admin 问"把休假规则翻译成计算公式"，回复是政策口径描述，未输出结构化公式。
- **根因**：HRStrategist 定位为**对话式政策顾问**，handler 无"公式生成"分支。
- **建议**：若需要，可新增"规则→公式"能力（PolicyAgent 输出 `IF/THEN` 结构化表达式 + 卡片）。
- **影响**：低（属能力扩展，非缺陷）。

### 🔵 P2 — 产品定位需澄清（非缺陷，建议文档说明）

**问题 3：聊天中说"调整某人额度"不会直接落库**
- **现象**：在对话里说"调整张伟年度配额"，HRStrategist 回"请告诉我调整谁/多少/理由，我会执行并留痕"，
  但真正执行需走 `/api/balance/adjust` 端点（且需 finance/sys_admin 权限）。
- **定性**：这是**有意的安全设计**——涉及金额变更的高敏操作不由聊天直接触发，必须经独立端点 + 权限校验 + 强制留痕。
- **建议**：在帮助文档中明确说明此设计（已在帮助中心"AI 助手·权限边界"板块体现）。

### ℹ️ 关于走查中一度报错的项（全部为测试参数名误用，非系统问题）

| 一度报错 | 真实原因 | 正确参数 |

| OCR 422 | 测试用了 `image` | 应为 `image_b64` |
| 审批 422 | 测试用了 `decision` | 应为 `status` |

| 聊天 422 | 测试用了 `text` | 应为 `message` |
| 报告导出 | 测试用了 `format`/`pptx` | 应为 `fmt`/`ppt` + `module_id` |

> **说明：以上均为我方测试脚本的参数名拼写问题，端点本身全部正常。已用正确参数复测通过。**
